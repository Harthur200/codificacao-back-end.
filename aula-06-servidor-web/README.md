# Aula 06 — Servidor Web

## 📚 Descrição

Nesta aula foi desenvolvido um servidor web utilizando o módulo nativo `http` do Node.js, sem a utilização de frameworks como Express.

O projeto demonstra como criar um servidor HTTP, receber requisições, identificar métodos e rotas, retornar diferentes códigos de status HTTP e adicionar cabeçalhos básicos de segurança às respostas.

## 🎯 Objetivos da Aula

- Criar um servidor HTTP utilizando o Node.js;
- Utilizar o módulo nativo `http`;
- Trabalhar com requisições e respostas HTTP;
- Identificar o método e a rota recebida;
- Criar uma rota `/status`;
- Retornar respostas no formato JSON;
- Trabalhar com códigos de status HTTP;
- Implementar uma resposta para páginas não encontradas;
- Adicionar cabeçalhos básicos de segurança;
- Utilizar ES Modules no projeto.

## 🛠️ Tecnologias Utilizadas

- Node.js
- JavaScript
- Módulo nativo `http`
- ES Modules
- npm
- Git e GitHub
