# Aula 05 — Variáveis de Ambiente, Configurações e Segurança

Este projeto apresenta o uso de **variáveis de ambiente no Node.js**, utilizando o pacote `dotenv` para carregar configurações externas da aplicação de forma organizada e segura.

O projeto demonstra como armazenar informações importantes, como **porta do servidor, chave de API e URL do banco de dados**, em variáveis de ambiente, evitando deixar essas informações diretamente no código-fonte.

---

## 📚 Objetivos

Nesta aula, foram estudados:

- Variáveis de ambiente;
- Arquivo `.env`;
- Arquivo `.env.example`;
- Arquivo `.gitignore`;
- Uso do `dotenv`;
- `process.env`;
- Validação de variáveis obrigatórias;
- Configuração de aplicações Node.js;
- Proteção de informações sensíveis;
- Gerenciamento de dependências com npm.
